微观经济学：从选择到均衡

当前进度：已精讲 886 页

一、这门课在讲什么

一句话：经济学研究的是「选择」，以及在资源稀缺的世界里，无数人的选择如何相互协调。

课件第一页就问了一个看似无关的问题：微信是免费的吗？ 微信不向你收钱，但它拿走你的时间；时间可以换成兼职收入、睡眠、社团活动。于是「免费」这个词就崩了——这正是全课的方法：把任何一件事都还原成成本与收益的对比，而成本是「你为此放弃的、最好的那个替代方案」。

由此得到贯穿全课的三层追问：

  1. 个体怎么选？（最优化：在约束下选最好的那个）
  2. 大家的选择怎么互相影响？（均衡：所有人都已尽力，没人想单方面改变）
  3. 这个结果好不好？该怎么评价、怎么改？（福利：剩余、效率、公平）

二、三条主线与三大支柱

课件第 40 页给出全课的骨架——经济分析的三大支柱：

支柱英文含义对应讲次
最优化Optimization在给定信息、预算、时间、能力的约束下，选可行方案里最好的那个第 1–4 讲
均衡Equilibrium每个人都在最优化，于是没人有激励单方面改变行为第 5、10 讲
实证检验Empiricism理论给出预测，预测要拿数据检验；相关不等于因果第 1 讲，贯穿全课

与之配套的三条主线是：

  • 主线 A：约束下的选择。 预算约束 → 无差异曲线 → 相切条件 → 需求曲线。（第 3 讲）厂商版：生产函数 → 成本曲线 → MR = MC → 供给曲线。（第 4 讲）
  • 主线 B：价格作为协调机制。 供给与需求相交得到均衡价格；价格同时传递信息、提供激励。计划经济之所以难，就难在它要把这两件事交给一个大脑。（第 2、5 讲）
  • 主线 C：福利评价。 消费者剩余 + 生产者剩余 = 社会总剩余；总剩余最大即「帕累托效率」；任何让交易量偏离均衡价的干预都会产生无谓损失。这套尺子后面用来量垄断（第 6 讲）、外部性（第 7 讲）、税收与管制（第 9 讲）。

四、四个模块，一条上升的路

模块 I｜方法论（第 1–2 讲） 先建立「经济学看世界的方式」：稀缺、选择、机会成本、边际、均衡、实证检验。第 2 讲把「最优化」写成可以计算的问题——目标函数、约束、一阶条件——这是后面所有模型的语法。

模块 II｜局部均衡的三件套（第 3–5 讲） 消费者（需求从哪来）→ 厂商（供给从哪来）→ 市场（两条曲线相交意味着什么）。学完这三讲，你应该能对任何一条新闻做「谁的需求/供给变了、价格和数量往哪走、谁受损谁受益」的三步分析。

模块 III｜市场失灵（第 6–9 讲） 完全竞争是基准，现实会偏离它：只有一家卖（垄断）、成本溢出到别人身上（外部性）、好东西人人想搭便车（公共品）、政府插手（税收与管制）。这四讲共用同一把尺子——社会总剩余——来衡量偏离的代价。

模块 IV｜策略与信息（第 10、12 讲） 当参与者少到「我一动你就动」时，供求分析不够用了，要用博弈论；当产品是信息、软件、平台时，边际成本近于零、用户越多越值钱，传统供求也要改写。

六、必须带走的 12 个式子

  1. 预算约束：Px·x + Py·y = I
  2. 边际替代率：MRS = MUx / MUy
  3. 消费者最优（内点解）：MRS = Px / Py
  4. 价格弹性：ε = (ΔQ/Q) ÷ (ΔP/P)，完全竞争厂商面对的需求弹性为无穷大
  5. 收益与弹性：MR = P(1 + 1/ε)，故垄断者只在 |ε| > 1 的区间生产
  6. 利润最大化：MR = MC
  7. 停业条件（短期）：P < AVC；退出条件（长期）：P < ATC
  8. 社会总剩余：TS = CS + PS，无谓损失是总剩余的减少量
  9. 税负分担：弹性小的一方承担更多；DWL ∝ t²（税率翻倍，DWL 约变四倍）
  10. 负外部性最优：MSB = MSC，庇古税 t = 边际外部成本
  11. 公共品最优（萨缪尔森条件）：Σ MB = MC（需求纵向加总，而非横向加总）
  12. 纳什均衡：给定他人策略，无人能通过单方面改策略而变好
